# Fortem Technologies

> Airspace security and defense company (Lindon, Utah) building counter-unmanned aircraft
> systems (C-UAS). The SkyDome System pairs TrueView AESA radars, long-range cameras, and RF
> sensors with the autonomous DroneHunter interceptor, orchestrated by SkyDome Manager
> command-and-control software. SkyDome Manager exposes REST, realtime, and track-only
> integration APIs for bi-directional data and command exchange with third-party C2 platforms
> (e.g. U.S. Army FAAD C2, Lockheed Martin systems). Backed by Lockheed Martin, DCVC, Toshiba,
> and Boeing. No public developer portal or open API specification is published; API access is
> arranged through defense/enterprise integration engagements.
